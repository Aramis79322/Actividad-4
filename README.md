# Cadenas y Punteros — Actividad 4: Control de Acceso en RAM

**Materia:** LPR — 5° Año 3° División A-B | **Prof.:** Prof. Mansilla Muñoz York Elías | **Est.:** Aramis Demaria

## Objetivo
Operar directamente sobre la RAM mediante punteros y desreferenciación para control de acceso por edad.

## Conceptos
`int* p = &edad` (p guarda dirección), `*p` (desreferencia), `&edad` (dirección), `p` (hex).

## Comandos
```powershell
g++ src/main.cpp -o src/cadenaspunteros.exe
.\src\cadenaspunteros.exe
```
